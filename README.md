## 服务端配置注意事项：

所有服务器都需要一个公共ip，并放行22端口（ssh，用于配置服务器）和443端口（用于sing-box连接）

建议仅允许使用ipv6登录SSH，避免ip扫描攻击（几乎所有云厂商的ipv6地址都是免费）

建议仅允许通过SSH密钥登录（GCP强制仅允许通过SSH密钥登录），如果需要使用密码，建议密码长度不小于12位，并且包含一个大写、一个小写、一个数字和一个特殊字符这四个选项中的至少3个

>使用"ssh-keygen -t [密钥算法，建议使用ed25519] -C <用户名>"生成密钥（windows和linux通用），运行这个命令之后按照提示操作即可

>完成之后去到存放密钥的文件夹，找到.pub的文件，打开并将里面的内容复制粘帖到你的虚拟机的authorized_keys里面或者在创建虚拟机的适当位置填入内容

>>GCP在创建虚拟机时的左边栏安全里面最底下展开管理访问权限，找到添加手动生成的SSH密钥，在下面点击添加项之后在输入框里面粘帖内容

>>>如果需要填入多个公钥，则多次点击添加项并在每一个框中填入一个

>>>如果后期需要增加密钥，则找到你的虚拟机（左上角三个横杠找到compute engine->虚拟机实例）并点击，之后顶部栏点击修改，下滑找到SSH密钥，点击添加项，填入密钥即可

>>azure里面在创建虚拟机首页下划找到管理员账户，身份验证类型选择SSH公钥，之后手动输入用户名，SSH公钥源选择使用现有公钥，之后在输入框内填入内容，可以填入多个公钥

>>>如果后期需要增加密钥，则找到你的虚拟机，之后左边栏找到帮助，展开找到重置密码，模式选择添加SSH公钥，输入用户名，SSH公钥源选择使用现有公钥，之后输入框内填写内容，可以填入多个公钥

对于微软azure云，服务器配置建议使用b2ats/b2pts（学生可免费使用），操作系统建议使用ubuntu，磁盘建议使用p6（对学生免费）

>创建完虚拟机之后在虚拟机->你的虚拟机名称->网络->网络规则里面添加上述入站规则（可选：可以添加入站规则并放行icmp流量）

针对GCP，建议使用e2-micro，磁盘建议使用30G标准持久磁盘，操作系统建议使用ubuntu

>创建完虚拟机之后在右上角导航菜单->VPC网络->VPC网络->点击你的VPC网络名称->顶部栏“防火墙”里面创建防火墙规则，需要允许所有出站流量和上述入站流量

具体创建方法见此链接：
https://drive.google.com/drive/folders/1R1ADiUCHaPJfhDfSqWEZEO7Rib2vKKfZ?usp=drive_link

在这个链接里面寻找对应sing-box版本，然后复制下载链接并使用wget命令下载：
https://github.com/SagerNet/sing-box/releases

之后按照模板创建服务端配置和客户端链接

使用sudo sing-box run -c "/路径/你的服务端配置"即可以指定配置运行singbox并开启vpn服务器

## 客户端连接操作：

电脑端使用v2rayN即可，在此处下载：https://github.com/2dust/v2rayN/releases
  
>在v2rayN底部栏打开tun开关和全局路由

>请务必检查顶部栏设置里面的tun设置里的MTU，确保其不大于1500，否则可能导致连接失败

>>建议将MTU设置为小于1420

>点击顶部闪电图标可以测试延时

>切换节点时，右键单击需要切换到的节点，之后点击设为活动即可

>（可选）在顶部栏设置里面的core类型设置将vless改为sing-box

>（可选）顶部栏设置里面的tun设置里面开启ipv6

安卓去此链接下载最新版v2rayNG:
https://github.com/2dust/v2rayNG/releases

>点击右上角+扫描二维码或者从剪切板导入即可导入配置
  
>点击右下角播放按钮即可连接

>点击右上角三个点里面可以测试延时

>切换节点时先断开现有连接，之后选择需要切换到的节点，然后重新连接

>（可选）建议在左上角菜单栏里面找到设置，下滑找到ipv6优先，并勾选

ios去app store搜索v2box下载

>需要海外apple id，建议使用欧美区域apple id

>去到底部栏第二个选项里面，通过右上角+从剪切板导入URI导入配置，也可以通过左上角扫码添加配置

>之后滑动滑块即可连接

>切换节点时先断开现有连接，之后选择需要切换到的节点，然后重新连接

>（可选）建议在底部栏第三个里面找到prefer ipv6并打开
