以上模板仅适用于版本号小于1.10.0的singbox

海外留学生可以使用学校账户创建微软azure云帐号并在认证为学生之后可以免费使用特定服务，可以用来搭建便宜vpn服务器

服务器配置建议使用b2ats/b2pts（学生可免费使用），操作系统建议使用ubuntu，磁盘建议使用p6（对学生免费），需要一个公共ip，并放行22号端口（用于ssh配置）以及443端口（用于sing-box连接）

创建完虚拟机之后在虚拟机->你的虚拟机名称->网络->网络规则里面添加出站规则并允许所有流量，（可选：可以添加入站规则并放行icmp流量）

在这个链接里面的大于20的页面去寻找对应版本，然后复制下载链接并使用wget命令下载

之后按照模板创建服务端和客户端配置

使用sudo sing-box run -c "/路径/你的服务端配置"即可以指定配置运行singbox并开启vpn服务器


电脑端使用v2rayN即可
  
    在v2rayN底部栏需要打开tun开关和全局路由

安卓和ios在应用商店（安卓为play商店,ios为app store）里面搜索sing-box并下载

  点击底部栏第三个图标，然后点击右下角+号选择手动创建配置
  
  点击创建的配置，之后点击编辑内容并按照客户端模板添加内容
  
  点击底部栏第一个图标之后选中指定配置，点击右下角播放按钮即可连接
  
    注意：连接上之后并不意味着可以成功上外网
  
  最后修改系统代理即可成功连接外网

如果自家宽带环境优异（拥有公网ipv4地址并且运营商允许用户使用自购的路由器），可以使用glinet-be9300或者其他可安装openwrt系统的路由器并在路由器上安装singbox
